# Building a Students’ Performance Dashboard in Microsoft Power BI

In this Power BI project project, I did EDA - clean, transform, analyze, and visualize education data using Power Query,
DAX, interactive charts, custom SVG visuals, and professional dashboard design techniques.

As a data analyst, this project creates a modern and interactive education analytics dashboard.

# Tools Used:
- Microsoft Power BI
- Microsoft Power Query
- DAX
- PowerPoint

# Dashboard Features:
🔹 Student Performance Analysis
🔹 Subject-wise Score Tracking
🔹 Demographic Insights
🔹 Grade Distribution Analysis
🔹 Interactive Filtering Experience
🔹 Modern Dashboard UI Design

# The project 
✅ Import and transform raw student performance data using Power Query
✅ Create DAX measures for KPIs and performance calculations
✅ Build KPI cards for total students, average scores & gender distribution
✅ Design interactive scatter plots and stacked bar charts
✅ Create custom SVG donut charts and progress bars
✅ Build a native box plot for statistical analysis
✅ Apply conditional formatting for grading categories (A–F)
✅ Use field parameters for dynamic analysis
✅ Add slicers, tooltips, navigation buttons & icons
✅ Design a professional dashboard background in PowerPoint
✅ Create a complete interactive education dashboard in Power BI
